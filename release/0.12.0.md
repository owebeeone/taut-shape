## Validation

- Compiler strict candidate gate: 2,645 native Windows tests plus four POSIX
  tests over the same candidate, with an exact 2,649-case union and no skips
  or omissions. The eight duplicate parity gate wrappers are accounted for
  separately; all 16 mandatory parity variants passed all 134 rows each.
  Metadata, standalone foundation packaging, distributions and smoke checks passed.
- Compiler publication CI: Python 3.10, 3.11, 3.12, 3.13 and 3.15 passed. These
  hosted Linux runs retain platform/optional-feature skips; they are additional
  coverage, not a replacement for the no-skip Windows/POSIX qualification.
- Rust shape: 109 tests, warnings-as-errors Clippy, no-default-features build
  and locked registry-only packaging passed in Gearu and publication CI.
- TypeScript shape: 316 tests, typecheck, frozen install and packaging passed.
- Python shape: 197 tests against published `taut-proto`, distribution builds
  and publication smoke checks passed. All five Python publication jobs passed.
- Live cross-language matrix, harness regressions and compatibility regression
  tests: 328 passed after the foundation registry lock was refreshed.

## Registry locks

`taut-shape-rs/Cargo.lock` now resolves `taut-foundation 0.12.0` from crates.io
with its real checksum. Glial's `pnpm-lock.yaml` now resolves the published
`@owebeeone/taut-shape 0.12.0`, replacing the previous local-file resolution.
Both updates were committed and pushed after publication. TypeScript shape's
unchanged development dependencies needed no lockfile edit.

## Resolved Glial consumer dependency

Glial's initial isolated release check exposed an existing unpublished dependency:
`@owebeeone/glade-decl 0.1.1` did not export the `./assistance` API already used
by Glial. A local source checkout was not accepted as a registry substitute.

After explicit authorization, Gearu released Glade declarations `0.2.0`.
Its [publication workflow](https://github.com/owebeeone/glade-decl-ts/actions/runs/43962158919)
passed all 29 tests, the build and an installed-tarball consumer check of both
the root and assistance subpaths, including a runtime codec round trip and
public TypeScript declarations. npm publication used trusted publishing and
signed provenance; the registry version was verified before updating Glial.

Glial now declares `@owebeeone/glade-decl ^0.2.0`, with a refreshed registry
lock. Its isolated release check passed all 196 tests, typechecking, packaging,
runtime imports and strict declaration checks for all four consumer entry points.
The [consumer CI check](https://github.com/owebeeone/glial-runtime/actions/runs/43962743341)
also passed against the committed dependency and lock update.
